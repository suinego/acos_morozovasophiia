# acos_morozovasophiia

Модуль ядра линукс разрешающий выполнять команды (через `execve`) только для заданного списка пользователей (UID) и на x86\_64

## Как работает?

Модуль перехватывает системный вызов `execve`, и проверяет, входит ли UID вызывающего пользователя в разрешённый список. Если не разрешенный id - ошибка`EPERM`.



## Как собрать?
```bash
make
```

Это соберёт модуль `uid_exec.ko` в папке `src/`.
Дальше загружаем модуль - 
   ```bash
   sudo insmod src/uid_exec.ko
   ```

Добавляем разрешенные id в `/proc/exec_allow` через пробел:

   ```bash
   echo "666 0" | sudo tee /proc/exec_allow
   ```
- то есть обычный юзер с id 666 и 0 root.

Тестируем:

   ```bash
   ./test/test_exec.sh
   ```

## Как происходит блокировка? 

Если юзер с id, не входящим в список, попытается выполнить программу - модуль заблокирует запуск:

```
[uid_exec] execve blocked for UID 99
```
